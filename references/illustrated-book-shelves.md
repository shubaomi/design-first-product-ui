# 插画书架与长篇阅读器

- 同级入口依阅读顺序成组。在桌面实景上核对与插画主体、标题和其他入口的间距，手机按可点按的尺寸排布。
- 读者选书以完整封面和书名为主。有公开入门书时将其排在视觉、DOM 和键盘顺序的第一位。首屏提供带可见标签的密钥输入和提交动作。选中受保护书后就地解锁，成功后返回目标书，错误可修正，关闭后恢复焦点。
- 封面作为独立展示资产，按内容方明确的公开范围提供。服务端继续校验正文与页图。核对访客、已解锁及退出后的真实响应。
- 长篇读者可随时查看当前卷、章和页，展开按卷分组的章节目录，一步返回书架。默认开书使用该设备与浏览器为本书保存的阅读位置，明确页码链接优先；从头阅读作为单独动作。若需求包含重进栏目直接续读，区分外部重进与主动返回书架。无记录、已读完、版本变化、存储不可用或授权失效各有可理解的入口。
- 使用真实多卷作品，在桌面与窄屏上验证首屏解锁、卷章边界、章节跳转、滚动与翻页后的保存、关闭再开、缩放后的恢复和键盘焦点。验证同页内阅读偏移是否需要保存，图片延迟加载时不得把旧书签覆盖为第一页。
- 航图等空间式书架给作品分配稳定 ID，已有地标和书签随版本保留。单图达到可读容量时开放下一图，并保留直接选书入口。使用一部新增测试作品验证跨图选书、解锁与续读，再发布真实新书。
