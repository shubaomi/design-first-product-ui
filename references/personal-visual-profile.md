# Personal Visual Profile

Use this file as a constraint record, not as a universal theme. Direct project instructions and an approved project `DESIGN.md` take precedence.

## Confirmed cross-project dislikes

- Reusing the same visual language across unrelated products.
- Default SaaS or admin-dashboard shells without evidence that monitoring is the primary job.
- Sidebar plus KPI cards plus dense tables as an automatic information architecture.
- Treating a dark theme as a shortcut to sophistication or a technical/AI identity.
- Repeating the warm beige and muted green visual family associated with prior Psychelog-style work.
- Pages dominated by visible inputs, selects, buttons, settings panels, and explanatory microcopy.
- Native-looking form controls used as the main visual composition.
- A redesign that changes only colors, radius, shadows, or typography while preserving the rejected layout archetype.

## Confirmed process preferences

- Research real products and viable interaction patterns before major UI implementation.
- Compare structurally different directions before selecting one.
- Keep essential actions obvious while reducing visible control density.
- Verify real desktop and mobile rendering and interaction.
- Preserve product-specific identity; do not make every project look like an operating system or dashboard.

## Not yet confirmed

Do not assume any of the following without project-specific approval:

- Light mode is always preferred.
- Editorial layouts are always preferred.
- A particular font, accent color, illustration style, or motion language should recur.
- Minimal information density is always better than focused density.
- Any referenced product should be copied as a complete style.

## How to evolve this profile

Only update this file after the user explicitly confirms that a preference should apply across projects. Record what is liked or disliked at the level of layout, hierarchy, interaction, typography, color, density, and motion rather than saving vague adjectives such as "premium" or "modern."
